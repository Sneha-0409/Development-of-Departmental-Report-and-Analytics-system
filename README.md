# 📊 InstiReport

> **A Full-Stack Annual Department Report & Analytics System for Educational Institutions**

InstiReport is a centralized web application that streamlines annual department report management across educational institutions. It enables students, faculty, report makers, and administrators to securely manage reports, automate documentation workflows, and visualize departmental analytics through an intuitive dashboard.

---

## ✨ Features

- 📄 Centralized annual report management
- 👥 Secure role-based authentication
- 📊 Interactive analytics dashboard
- ⚡ Automated report generation
- 📱 Fully responsive user interface
- 🔐 Firebase Authentication
